# Смарт-ОК

Адаптивная современная версия сайта смарт-ок.рф: IP-телефония для бизнеса, CRM-интеграция, масштабирование и поддержка.

Статические HTML/CSS/JS, без сборки и установки зависимостей. GitHub Pages: `main` → `/(root)`. Файл `.nojekyll` сохранён.

Логотип и фотографии оригинальные, источники — `assets/sources.json`. Шрифт Manrope: `assets/fonts/OFL.txt`.

Форма подготавливает письмо в почтовом приложении посетителя или копирует запрос. Автоматической отправки и хранения данных нет. Телефон, email и карта работают как прямые ссылки.
